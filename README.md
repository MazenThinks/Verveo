# Verveo

A premium e-commerce product discovery platform focused on browsing experience and visual clarity.
https://verveo.vercel.app/

## Features

- 🎨 Modern, minimal design
- 🔍 Intuitive product discovery
- ✨ Subtle animations with Framer Motion
- 📱 Fully responsive
- ⚡ Built with Vite + React

## Tech Stack

- React 18
- React Router
- Tailwind CSS
- Framer Motion
- Vite

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Design Philosophy

Verveo emphasizes:
- Visual clarity over feature density
- Calm, premium user experience
- Content-first approach
- Thoughtful interactions
